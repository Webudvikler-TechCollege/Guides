# Symboler i programmering

| Symbol | Navn (EN)        | Navn (DA)             | Windows (DK)     | Mac (DK)        |
|--------|------------------|------------------------|------------------|-----------------|
| ()     | Parentheses      | Parenteser             | Shift + 8 / 9    | Shift + 8 / 9   |
| {}     | Curly braces     | Tuborgklammer          | AltGr + 7 / 0    | Alt + 8 / 9     |
| []     | Square brackets  | Firkantede parenteser  | AltGr + 8 / 9    | Alt + 5 / 6     |
| <>     | Angle brackets   | Spidse parenteser      | < ved Shift      | Shift + <       |
| =      | Equals           | Lighedstegn            | =                | =               |
| ==     | Equality         | Sammenligning          | = + =            | = + =           |
| ===    | Strict equality  | Streng lighed          | = = =            | = = =           |
| !      | Exclamation mark | Udråbstegn             | Shift + 1        | Shift + 1       |
| !=     | Not equal        | Ikke lig               | ! + =            | ! + =           |
| !==    | Strict not equal | Streng ikke lig        | ! + ==           | ! + ==          |
| +      | Plus             | Plus                   | +                | +               |
| -      | Minus            | Minus                  | -                | -               |
| *      | Asterisk         | Stjerne                | Shift + '        | Shift + '       |
| /      | Slash            | Skråstreg              | /                | /               |
| \      | Backslash        | Backslash              | AltGr + +        | Alt + Shift + 7 |
| .      | Dot              | Punktum                | .                | .               |
| ,      | Comma            | Komma                  | ,                | ,               |
| :      | Colon            | Kolon                  | Shift + .        | Shift + .       |
| ;      | Semicolon        | Semikolon              | Shift + ,        | Shift + ,       |
| '      | Single quote     | Apostrof               | '                | '               |
| "      | Double quote     | Gåseøjne               | Shift + 2        | Shift + 2       |
| `      | Backtick         | Backtick               | AltGr + ´        | Alt + ´         |
| &      | Ampersand        | Og-tegn                | Shift + 6        | Shift + 6       |
| \|     | Pipe             | Lodret streg           | AltGr + <        | Alt + i         |
| ?      | Question mark    | Spørgsmålstegn         | Shift + -        | Shift + -       |
| #      | Hash             | Nummertegn             | Shift + 3        | Alt + 3         |
| $      | Dollar           | Dollar                 | Shift + 4        | Shift + 4       |
| %      | Percent          | Procent                | Shift + 5        | Shift + 5       |
| @      | At               | Snabel-a               | AltGr + 2        | Alt + 2         |
